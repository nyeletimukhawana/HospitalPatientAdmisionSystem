# HospitalPatientAdmisionSystem
Admission System For Patients
- Developed a console-based hospital patient admission system to replace a paper-based admission process.
- Implemented functionality to register and maintain patient information.
- Developed features for allocating and releasing hospital beds
- Implemented functionality to view patient and bed information and generated basic ward reports.
- Applied Java concepts including Arrays, ArrayLists, methods, nested loops, inheritance, information hiding, exception handling and Unit Testing.
